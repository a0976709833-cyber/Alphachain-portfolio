# AlphaChain｜半導體產業研究系統

**個人專案｜Python｜資料處理｜軟體工程實作**

## 專案介紹

AlphaChain 是一項持續開發中的個人研究專案，目標是建立可追溯資料來源、驗證證據並分析半導體產業供應鏈關係的研究系統。

專案著重於資料可信度、系統化研究流程，以及如何區分已知事實、合理推論與尚未確認的假設。

## 使用技術

- **Python**：系統邏輯與資料處理
- **Pydantic**：資料模型定義與驗證
- **CSV**：結構化研究資料管理
- **Git / GitHub**：版本控制與程式碼審查
- **VS Code**：開發環境
- **AI 輔助開發**：協助程式實作、除錯與技術探索

## 系統核心流程

事件輸入 → 企業與供應鏈關係 → 證據蒐集 → 資料驗證 → 因果機制分析 → 研究結果輸出

## 技術展示

- [Python 證據資料驗證示範（含程式碼、測試及執行說明）](validation-demo/README.md)：使用虛構資料展示 Pydantic 欄位驗證與基本一致性檢查；為 AI 輔助編寫的獨立簡化示範，並非 AlphaChain 主專案原始碼。
